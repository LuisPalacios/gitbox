# Upcoming release notes

## Repository transfers and branch sweep

Gitbox retires **Move repository…**. Use the provider’s transfer feature or copy refs manually with `git push --mirror` from a mirror clone to an empty destination. See the [transfer guide](gui-guide.md#transfer-a-repository-across-accounts-or-providers).

**Sweep branches** deletes only merged branches. To review branches with a missing upstream or squash-equivalent changes, open the clone in your Git client. Mirrors continue to run on provider servers.
